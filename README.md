# cozy-anonymous-circles

> Anonymous location-based circles and interactions.

## 📖 Overview
A modern React web application built with Vite, styled with Tailwind CSS and Radix UI (shadcn), and utilizing Mapbox for geolocation features and Supabase for backend services.

## 🛠️ Built With
* **Framework:** React `18.3.1` (TypeScript)
* **Build Tool:** Vite `5.4.1`
* **Styling:** Tailwind CSS & Radix UI
* **Key Integrations:**
  * Supabase `2.50.0`
  * Mapbox GL `3.12.0`

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher)
* npm or yarn

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/mohitshukla02/cozy-anonymous-circles.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```
